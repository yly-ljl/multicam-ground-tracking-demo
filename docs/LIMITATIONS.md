# 失败案例与能力限制

更新：2026-10-30。返回[详细结果](RESULTS.md)。C1/C2/C3是相机编号，双相机B2使用C1+C2，默认三相机B3使用C1+C2+C3。GLOBAL与SOFT分别是E005、E006尝试但未采用的时间关联候选。

## 哪些环节仍会失败

- **地面定位**：系统假定固定标定、同步去畸变相机和地面Z=0，没有人体高度、完整三维框、移动相机或任意场景标定能力。检测框底中心是脚点近似，遮挡、截断和多人框都会带来偏差；标注框底也不是独立接地点真值。
- **同帧融合**：按固定相机顺序合组，不是全局多视角最优。几何门内可能包含不同的人，同一人也可能分成多组。第三相机没有加入已有组而形成的新单组中包含真实新增覆盖，不能简单删除。
- **时间关联**：默认方法没有外观身份信息，纯距离继承仍会换人、切分，或与暂时失去观测的轨迹竞争。轨迹编号数不是人数，减少编号也不等于质量提高。
- **指标解释**：位置召回与身份保持是不同能力；匹配成功子集的距离下降不保证整体改善。E001原单相机可见标注1879人时刻与后续整个评价区域2152人时刻不同。评价中的SWITCH和IDTP也不能替代视觉确认，详见[协议](EVALUATION.md)。

## 有限案例说明了什么

以下帧编号均来自同一场景。旧开发是0–495，新开发是500–795；800–1395是已使用的对照片段，原用于E003验证、后用于研究比较。案例编号C01/C17等是E007的窗口编号，与相机编号C1/C2/C3不同。

**时间错误继承。** 旧开发帧255中，基线将围巾浅裤人物187接到此前人物136的轨迹；SOFT在该局部保留了两条正确对应。对照片段帧840中，GLOBAL为增加配对而让人物193继承此前人物455的轨迹，SOFT避开了该错误。但旧开发帧210中SOFT仍接受139红衣人物→149蓝衣人物的错误继承。两个候选的整段采用要求均未通过。

**同一时刻不同人物被合组。** E007窗口C17（新开发525）、C29（对照片段800）、C30（对照片段890）提供三个不同窗口的支持例。C29中C1/C2对应格子衣女性218，而C3对应黑短袖男性55；C30中C2对应浅蓝裤人物376，C3对应长发红/深色外套人物358。旧开发75的C05也支持C2/C3成员来自不同人，但遮挡使得加入C3前的双相机组是否已混合无法确认，不能据它单独断言错误由C3引入。

**不能简化为一次身份切换。** C01显示的是人物0的历史组接到含0/1的混合组，并非整个组从0换成1；C24需要分别看清双相机、三相机各自的成员，不能把两条件拼图的并集当成一个三相机组。每段起点尚无前次继承，却也可能出现整段身份匹配差异，因此身份正确数的损失不一定是当帧串人。

**正常与不确定情况也存在。** 低置信度、多成员融合或较大位置位移都可能对应正常观测，不能单凭阈值或残差判断身份错误；边缘碎片、遮挡与缺少标注提示的案例仍有无法确认的部分。

这些描述来自原研究图像检查，仓库不附带逐例原图，因而不是可独立重审的图像证据包。它们用于解释现象与提出假设，不代表总体错误发生率。

## 结论和复现范围

E007仅检查36个分层随机窗口和12个目的窗口，每窗最多3个时刻；重复人物、相邻帧不是独立复现。尚不能确定总体主因、各环节因果贡献或显著性。外观相似性辅助合组只是待验证方向，也可能错拒同人、增加单组和轨迹竞争。

三个已使用片段均来自同一场景；1400–1995仍未用于实验，跨场景泛化未知。E003/E005/E006均未通过采用要求。B3作为研究三视角覆盖与身份代价的基线保留，B2仍是重要对照。

仓库内四个预测CSV支持三相机缓存回放，但没有GT、完整历史身份距离/映射和48窗图证，不能据此独立复算所有实验。运行还需外部资产，见[快速开始](QUICKSTART.md)。已有性能数据来自同模型的小片段三遍共180次真实图像调用，播放2fps不是推理速度，也不构成生产实时能力结论。
