- **任务能力**：固定标定、同步去畸变相机，地面Z=0；没有人体高度、完整3D框、移动相机或任意场景标定能力。预训练检测器未在本项目训练。
- **脚点和可见性**：框底中心受遮挡、截断、多人框影响；GT框底也不是独立接地点真值。边缘距离/置信度/几何残差是线索，不自动等于定位方差或身份概率。
- **同帧融合**：相机顺序固定，不是全局多视角最优；几何门内可异人混合，同人也可分裂成多组。C3单组有真实新增覆盖，不能批量删除来制造指标改善。
- **时间关联**：无外观身份信息，纯距离继承仍会换人、切分或与纯预测竞争。总体ID数不是人数，减少ID也不能当质量提升。
- **评价**：只用三个已见片段、地面点协议；匹配子集距离变小不保证覆盖或身份改善。E001原C1可见GT分母1879与E002/E004全ROI2152不同，不直接混比。原GT344疑点保留；SWITCH和IDTP不替代视觉确认。
- **诊断**：E007九层各4随机单元及12目的窗、每窗≤3时刻。模糊项保留，不换样；重复人物与邻近帧不作独立复现，不给总体语义比例、显著性或各环节因果贡献。
- **复现范围**：首传四个预测CSV可支持B3参考回放，不能复算全部历史身份映射、矩阵、48窗和七轮完整结果；完整外部数据/档案需另备。首传没有原图媒体，失败案例仅以有边界的文字和数值呈现。
- **性能**：原性能证据为同模型的小片段三遍共180次真实图像调用；播放2fps不等于推理fps。没有清OS缓存，不称冷启动磁盘测试；未做生产实时认证。本次整理只做CPU缓存回放，没有重测GPU吞吐。
- **泛化与决策**：E003/E005/E006未通过其采用要求，仍保留B3；E007仅提名进一步研究同帧外观一致性，未实施或证明有效。1400–1995未启用，未开始E008。

## 有限失败事实

旧开发255帧局部竞争中，基线将围巾浅裤人物187继承到136的轨迹；SOFT在该局部可保两条对应，但三段整体标准仍失败。参考840帧GLOBAL为多配对损害193近邻，SOFT局部避开；旧开发210帧SOFT仍接受139红衣→149蓝衣错误继承。这些是局部图证解释，不代表总体发生率。

E007的C17（新开发525）、C29（参考800）、C30（参考890）为审查认可的三个非重复同帧异人组合窗口，另有低置信/多成员融合正常反例。旧开发75为C05：C2/C3外观不同支持该组混合，但B2父组是否此前已混合受遮挡影响、不确定，不能据它单独证明错误由C3才引入。C01曾被错误概括为整组0→1，实际是0历史组接到含0/1混合组；C24必须分清B2/B3各自成员，不能把拼图并集当B3前组。更正保留在研究原件中，本发布文字采用审查后的限定结论，原图未纳首传。

上述文字不是一个独立可重审的图像证据包；本仓库同时提供汇总来源标识与协议，避免把未提供的原图当作读者已验证事实。
