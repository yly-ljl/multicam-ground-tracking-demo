# 代码、数据表与结论的来源

更新：2026-10-30。返回[目录导航](../ARCHITECTURE.md)。本仓库整理了 E001–E007 的实现和研究结果；源码基于2026-10-30的实际研究工作区，包含当时已有的中文学习注释和说明字符串。

## 实现与可核对的数值

[SOURCE_MANIFEST.csv](SOURCE_MANIFEST.csv)列出原49份源码、配置、测试、辅助脚本和依赖文件，以及16份数值文件的来源路径、字节数和SHA256。这些路径是原研究布局的来源标识，不表示相应目录全部随本仓库提供。

| 材料 | 来源与用途 |
|---|---|
| 生产代码、原实验配置和测试 | E001–E007研究实现；保留等权融合及原贪心跟踪为默认，候选与诊断模块单独存在。 |
| [汇总表](../results/summary/README.md) | E002空间对比、E003加权对比、E004身份/空间结果、E005/E006候选与采用门槛、E007四集合/结构/人工计数。 |
| [三相机预测缓存](../results/b3_reference/README.md) | 来自 E003 的800–1395等权运行，包含三路观测与B3轨迹；对应已使用的对照片段。 |
| [实验摘要](../experiments/README.md) | 根据各轮研究报告与结果表整理；每页注明研究来源，E007保留有限案例和不确定项。 |
| docs/assets/ 自绘图 | 方法流程来自实现关系，身份图来自随附CSV；生成入口为 [build_public_figures.py](../scripts/build_public_figures.py)。 |

`public_demo_reference.json` 将演示入口连接到仓库内缓存；`run_cpu_tests.py` 提供可选择外部标定测试的开发入口。这两者是阅读和运行包装，不改变预测方法。

## 能据此复核什么

可以阅读精确汇总、检查代码，并在自行取得原图和标定后重新融合/跟踪缓存。完整身份重评还需要原GT和相应轨迹；16份数值文件不能单独重建全部实验的身份距离矩阵、全局映射或E007的48个图像窗口。

原图、标定、权重、完整研究输出和逐例媒体不在仓库中。数据与模型来源见[DATA_AND_MODELS](DATA_AND_MODELS.md)，评价定义见[EVALUATION](EVALUATION.md)，固定快照与文档更新关系见[VERSION](VERSION.md)。
