# 地面位置与轨迹身份怎样评价

更新：2026-10-30。返回[详细结果](RESULTS.md)。评价基础在 E004 建立，后续实验沿用。这里评价的是地面点，不是二维框或完整三维框，也不是官方完整 WILDTRACK 协议。

## 先约定对象、单位与数据片段

**GT（ground truth，真实标注）**来自数据集的 personID 和 positionID；后者转换为米制地面坐标。**ROI（region of interest，评价区域）**固定为半开矩形 `[-3,9)×[-9,27)`，单位为米，左/下边界包含、右/上边界不包含。每段使用该区域内全部标注，不随所选相机的可见框改变分母。

计数单位是**人时刻**：一人在一个采样时刻出现计1次，同一人在100个时刻出现计100次。因此“GT 2152”不是2152个不同的人。每次时间更新称为一个 tick，即一个采样时刻。

C1/C2/C3 是三个相机编号；单相机条件为 C1，双相机 B2 使用 C1+C2，三相机 B3 使用 C1+C2+C3。不同条件的轨迹编号独立，相同数字不表示同一个人。

| 文中名称 | 原字段 | 帧编号 / 时刻数 | 使用背景 |
|---|---|---|---|
| 旧开发片段 | `old_development` | 0–495 / 100 | 最先使用的片段 |
| 新开发片段 | `new_development` | 500–795 / 60 | 后来加入的片段 |
| 已使用的对照片段 | `seen_reference` | 800–1395 / 120 | 原在 E003 用于验证，后已用于分析和比较，不能当作未使用测试段 |

旧/新仅指本项目使用顺序，三段均为同一场景。“已使用”指用于研究分析和比较，不表示用来训练检测器；检测器使用预训练权重。相邻采样帧编号相差5，物理时间相差0.5秒；每段从空跟踪状态独立运行，不合并分母。1400–1995仍未用于实验。

## 空间评价：位置有没有覆盖到

预测分为三个池，分别评价：

| 原字段 | 含义 |
|---|---|
| `raw_observations` | 跟踪前的地面观测；多相机条件中为同帧融合后的组位置 |
| `filtered_observed`（简称 observed） | 当前有检测观测支持、经过滤波的轨迹位置 |
| `pure_predictions`（简称 predicted） | 当前没有观测支持、仅由运动模型外推的位置 |

每时刻、每个池都做一对一位置匹配：欧氏距离≤1米才合法，先最大化合法匹配数，再最小化总距离。位置精确率 P＝匹配数/区域内预测数；位置召回率 R＝匹配数/GT数。mean、median、P90、P95 是匹配成功子集的距离统计，不能代表全部目标误差。三个池的匹配数不能相加，也不能当作身份正确数。

`full_roi` 指整个评价区域。`common_projected` 指 C1/C2/C3 对地面点均为正深度且回投在图内的共同投影区域，不意味着行人无遮挡。历史空间表在各自区域内重新匹配；E007按GT位置切分全区域匹配结果，两者不是同一口径。

E001最初只用 C1 可见GT（1879人时刻）；首页和后续单/双/三相机表使用全区域GT（2152人时刻）。两个分母不能直接比较。新开发/对照片段的 B3 原始融合组为1631/3569，而区域内 observed 为1629/3568，也须区分。

## 身份评价：整段中是否持续跟对同一个人

只使用区域内 observed 的滤波位置和 track_id。每时刻输入完整的“GT×预测”欧氏距离矩阵：距离≤1米合法，其余不可匹配，而不是只输入空间评价选出的获胜配对。各段、各方案单独求整段轨迹与真实身份的全局对应。

在该对应下，IDTP 是身份匹配成功的人时刻数，IDFP 是未正确对应的预测人时刻数，IDFN 是未正确对应的GT人时刻数：

- 身份精确率 `IDP = IDTP / (IDTP + IDFP)`。
- 身份召回率 `IDR = IDTP / (IDTP + IDFN)`。
- `IDF1 = 2×IDTP / (2×IDTP + IDFP + IDFN) = 2×IDTP / (GT数 + 预测数)`。

因此，IDTP增加并不保证IDF1提高：预测总数和错误也可能增加。整段身份对应会受其它时刻影响，某帧有近距离匹配或计入IDTP，不保证该帧视觉身份正确。库中的 SWITCH/fragmentation 也不是逐例看图确认的串人次数；原标注中 personID 344 的疑点保留，不据此删改GT。

实现使用 motmetrics 1.4.0 与 SciPy 求解，显式 frameid、`max_switch_time=infinity`，空帧也更新，缺标注报错；预测点是否在ROI内按当前坐标重算。项目未实施 HOTA。实现入口：[identity_evaluation.py](../tracking_demo/identity_evaluation.py)；库定义：[metrics.py](https://github.com/cheind/py-motmetrics/blob/v1.4.0/motmetrics/metrics.py)、[mot.py](https://github.com/cheind/py-motmetrics/blob/v1.4.0/motmetrics/mot.py)。

## 候选比较与诊断

E005/E006保持 B3 同帧组成员及位置，只替换时间分配。采用要求事先确定：已使用的对照片段 IDF1 至少提高3个百分点；两个开发片段各不低于基线1个百分点；三段空间 P/R 各不低于基线1个百分点，P90距离增加不超过0.05米。判断使用未四舍五入值，任一要求失败即不采用。完整结果见[候选补充](RESULTS.md#补充位置加权与时间关联候选)。

E007复用各完整运行的整段身份对应，把全部GT人时刻分成“两者均正确、仅双相机正确、仅三相机正确、两者均不正确”。分层后不重新求身份映射；融合父组按原成员恢复。这个拆分描述结果变化，不是各模块因果贡献的分解。
