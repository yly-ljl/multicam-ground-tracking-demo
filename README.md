# 多相机行人地面定位与跟踪

这个项目研究一个问题：**增加相机后，能否看见更多行人，并持续保持正确的行人身份？** 它使用 WILDTRACK 同一场景的固定标定相机，构建从图像检测到地面轨迹的离线 demo，再分析多相机融合带来的收益与错误。

输出是以米为单位的地面位置 **(X, Y, 0)** 和轨迹编号，不包含人体高度或完整三维框。

## 方法与实验主线

C1、C2、C3 表示数据集中的第1、2、3号相机。单相机方案使用 C1；双相机方案使用 C1+C2，简称 **B2**；默认三相机方案使用 C1+C2+C3，简称 **B3**。

方法是：预训练 YOLO11n 检测行人 → 以检测框底边中心近似脚点并投影到地面 → 将同一时刻、位置接近的跨相机观测合组并取等权平均 → 通过距离关联和 Kalman 滤波维护跨时刻轨迹。真实标注只用于事后评价。

实验用 E001–E007 编号，建议沿以下主线阅读：

| 实验 | 回答的问题 | 得到的结果 |
|---|---|---|
| [E001：单相机闭环](experiments/E001_baseline/README.md) | 图像中的行人如何变成米制地面轨迹？ | 接通检测、投影、跟踪与展示，明确遮挡和脚点近似的局限。 |
| [E002：双/三相机融合](experiments/E002_multicam/README.md) | 更多视角带来什么？ | 地面位置覆盖增加，同时出现更多未匹配输出、异人误融合和同人分裂。 |

## 主要结果

下表比较同一段图像（帧编号0–495，共100个采样时刻），使用同一个地面评价区域和全部真实标注。只评价当时有检测支持的轨迹位置，不把暂时失去检测后的外推位置混入。

- **地面位置召回率**：真实标注中，有多少能在1米内与预测位置一对一匹配；它衡量位置覆盖，不要求跨时刻身份一致。
- **IDF1**：在整段轨迹身份对应下，综合身份匹配精确率与召回率的分数；这里也使用1米地面距离门限，越高越好。

| 方案 | 地面位置召回率 | 身份分数 IDF1 |
|---|---:|---:|
| 单相机 C1 | 40.66% | 46.20% |
| 双相机 B2 | 68.22% | 59.79% |
| 默认三相机 B3 | 82.43% | 55.47% |

从双相机增加到三相机后，位置覆盖继续提高，身份分数反而下降。B3保留为研究三视角覆盖与身份代价的基线，B2是重要对照，并不表示B3综合最好。E007发现：新增视角既补充了真实覆盖，也可能把不同的人合入同一组；新增的正确身份匹配与原有匹配的损失同时存在。这解释了需要分别检查覆盖和身份的原因，但有限案例不足以给出各类错误的总体占比或确定主因。

上述是项目自定义片段与评价协议，**不是官方完整 WILDTRACK 成绩**。另外两段的比较、精确计数及候选负结果见[详细结果](docs/RESULTS.md)，指标定义见[评价协议](docs/EVALUATION.md)。
