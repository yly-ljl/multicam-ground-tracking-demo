# E003：组内投影敏感度加权未采用

更新：2026-10-30。返回[实验索引](../README.md)。

这个补充实验试图减少跨相机地面位置误差。保持三相机 B3 的融合组成员不变，仅将组内等权平均改为按逆局部投影敏感度 `trace(JJᵀ)` 归一加权，J为图像到地面投影的局部Jacobian。该变化不修复成员误融合或同人分裂。

采用要求预先设为：两个片段的观测位置匹配数均不下降，且匹配距离均值均下降。

| 片段 | 等权→加权匹配数 | 等权→加权均值（米） |
|---|---:|---:|
| 旧开发0–495 | 1774→1768 | 0.304886→0.311240 |
| 已使用的对照片段800–1395 | 2634→2629 | 0.299867→0.296847 |

**未达到要求，保留等权。** 后一段均值下降约3毫米，却损失了位置覆盖；两种方法匹配成功的子集也不同，不能理解为同一批行人都更准确。

800–1395原在本实验中用于验证，后已用于分析和比较，因此现在称为“已使用的对照片段”，不是未使用测试段。旧开发指本项目最先使用的同场景片段。

精确数据：[旧开发](../../results/summary/E003_development_spatial.csv)、[对照片段](../../results/summary/E003_reference_spatial.csv)。评价口径见[协议](../../docs/EVALUATION.md)，完整上下文见[详细结果](../../docs/RESULTS.md)。研究来源：原 `outputs/E003_improvement/development` 与 `validation` 下的 `comparison.csv` 及实验报告。
