# E001：从单相机图像到地面轨迹

更新：2026-10-30。返回[实验索引](../README.md)。

本实验使用第1号相机 C1，先接通检测、地面定位、时间跟踪和展示。预训练 YOLO11n 检测行人，以检测框底边中心近似脚点，经固定标定投影到以米为单位的地面，再以0.5秒物理时间步维护轨迹。结果为地面(X,Y,0)，不估计人体高度或三维框。

最初使用帧编号0–495的100个采样时刻（后称旧开发片段），按 C1 可见标注评价。真实标注 GT 共1879人时刻——一人在一个时刻计一次；只统计当前有观测支持的轨迹位置。1米内一对一位置匹配868，未匹配预测175，未匹配GT 1011，匹配距离均值0.2738米。

遮挡和截断会使框底偏离实际接地点。暂时没有检测的轨迹可由运动模型外推，但不复用旧检测框，也不与有观测的位置混合计分；轨迹编号总数不等于真实人数。

后续比较单/双/三相机时改用整个地面评价区域的2152个GT人时刻，不能直接将两个口径的匹配数作性能增量。下一步主线见[E002](../E002_multicam/README.md)，具体定义见[评价协议](../../docs/EVALUATION.md)。
