# E007：为什么覆盖增加，身份分数却可能下降

更新：2026-10-30。返回[实验索引](../README.md)。

本实验不提出新跟踪算法，而是复用双相机 B2（C1+C2）与三相机 B3（C1+C2+C3）的已有结果，检查第三相机带来的新增覆盖、损失与融合结构。

IDF1是整段身份保持分数。它不仅取决于正确匹配数，还取决于预测总数和错误；“位置覆盖更多”或“正确匹配更多”都不必然提高IDF1。将全部真实标注按各自整段身份对应分组，可以看出正确匹配的新增与损失并存。计数单位为人时刻，即一人在一个时刻计一次：

| 片段 | 仅三相机正确（新增） | 仅双相机正确（损失） | 净增 |
|---|---:|---:|---:|
| 旧开发0–495 | 354 | 229 | 125 |
| 新开发500–795 | 207 | 102 | 105 |
| 已使用的对照片段800–1395 | 356 | 309 | 47 |

旧/新指同场景片段的使用顺序；800–1395原在E003用于验证，后已用于分析比较，不能当作未使用测试段。完整四集合及位置匹配拆分见[详细结果](../../docs/RESULTS.md)。

## 案例观察支持什么

双相机父组指加入C3前已有的C1/C2融合组；新单组指C3观测没有加入已有组而单独形成的组。按原始成员对应7843个三相机组、10515个成员与双相机父组后，检查36个分层随机窗口和12个目的窗口，每窗最多3个时刻。观察到：

- 第三相机能补充真实行人覆盖，新单组不能简单当作噪声删除。
- 几何距离门内也可能组合不同的人；同帧合组值得进一步检查。
- 低置信度、大位移或多成员并不自动表示错误；遮挡和边缘碎片中仍有无法确认的情况。

这些观察尚不能确认总体主因，也不能估计各类错误的总体比例。整段身份对应受其它时刻影响，“仅双相机正确”不能直接解释为该帧发生了错误继承；两方案图像的并集也不是单个三相机组。

下一步拟验证用外观相似性辅助判断同一时刻的跨相机观测是否来自同一人。它可能减少异人组合，也可能错拒同人、增加单组与轨迹竞争；尚未实现或证明带来提升，默认三相机等权融合与原时间关联不变。
