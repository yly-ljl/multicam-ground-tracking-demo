# E006：允许有限未匹配代价的时间关联未采用

更新：2026-10-30。返回[实验索引](../README.md)。

E005提示强制尽量多配对可能保留坏匹配。本补充实验使用 **SOFT**，仍固定三相机 B3（C1+C2+C3）的融合组、滤波和生命周期，在严格小于1.5米的门内，以配对距离除以1.5作为代价；当前观测不继承旧轨迹的代价为1，旧轨迹未匹配的代价为0。未继承的观测照常建立新轨迹。

相对默认B3，整段身份分数IDF1的变化如下：

| 片段 | IDF1变化（百分点） |
|---|---:|
| 旧开发0–495 | -0.83 |
| 新开发500–795 | -1.49 |
| 已使用的对照片段800–1395 | +2.34 |

旧/新开发是同场景片段的使用顺序；800–1395原在E003用于验证，后已用于分析比较，不是未使用测试段。采用要求仍以默认B3为对照：新开发最多允许下降1个百分点，对照片段至少提高3个百分点。两项均未达到；其余10项通过，**SOFT未采用，默认B3不变**。

旧开发帧255和对照片段帧840存在局部改善，但旧开发帧210仍出现139红衣人物→149蓝衣人物的错误继承。局部对应与整段身份计分可能有不同变化，不能据局部正例推断整体有效。
