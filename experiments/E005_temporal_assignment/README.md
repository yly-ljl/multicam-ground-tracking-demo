# E005：优先最大配对数的时间关联未采用

更新：2026-10-30。返回[实验索引](../README.md)。

这个补充实验尝试改变跨时刻的轨迹继承。固定默认三相机 B3（C1+C2+C3）的同帧融合组、滤波与生命周期，仅将原贪心关联换成 **GLOBAL**：距离严格小于1.5米时允许配对，先最大化合法配对数，再最小化总距离。

IDF1是整段身份保持分数，定义与事先确定的采用要求见[评价协议](../../docs/EVALUATION.md)。相对默认B3的变化为：

| 片段 | IDF1变化（百分点） |
|---|---:|
| 旧开发0–495 | -2.75 |
| 新开发500–795 | -5.89 |
| 已使用的对照片段800–1395 | -0.76 |

三项身份要求均失败，九项空间约束通过，**GLOBAL未采用**。旧/新开发只是同场景片段的使用顺序；800–1395原在E003用于验证，后已用于分析比较，不是未使用测试段。

旧开发帧255的局部竞争支持重新考虑分配方式，但“更多配对”不保证身份正确。对照片段帧840中，GLOBAL为增加配对，让人物193错误继承了此前人物455的轨迹。局部动机不能代替整段效果。

精确表：[身份结果](../../results/summary/E005_identity.csv)、[采用门槛](../../results/summary/E005_thresholds.csv)。与后续SOFT的对比见[详细结果](../../docs/RESULTS.md)。研究来源：原 `outputs/E005_temporal_assignment/identity_summary.csv`、`thresholds.csv` 及实验报告。
