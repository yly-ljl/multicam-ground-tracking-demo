# 实验阅读索引

更新：2026-10-30。返回[首页](../README.md)。E001–E007是本项目按研究顺序编号的实验。建议先读单相机闭环、多相机结果和收益/代价诊断，再按需要查评价基础及候选补充。

## 主线

| 实验 | 研究问题 | 主要结论 |
|---|---|---|
| [E001：单相机闭环](E001_baseline/README.md) | 怎样从图像得到米制地面轨迹？ | 完成检测、投影和时间跟踪；框底脚点近似仍受遮挡影响。 |
| [E002：双/三相机融合](E002_multicam/README.md) | 增加视角带来多少覆盖？ | 位置覆盖提高，但额外输出、误融合和分裂并存。 |
| [E007：观测收益与代价诊断](E007_observation_diagnosis/README.md) | 为什么覆盖提高但身份分数下降？ | 分开新增与损失，有限案例支持外观一致性作为待验证方向；总体主因未定。 |

## 评价基础与补充负结果

| 实验 | 内容 | 结果 |
|---|---|---|
