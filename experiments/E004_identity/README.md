# E004：区分位置覆盖与身份保持

更新：2026-10-30。返回[实验索引](../README.md)。

位置接近并不保证始终跟对同一个人。本实验在地面位置评价之外建立整段身份评价：每个采样时刻保留全部真实标注与预测之间的距离关系，再求整段轨迹与真实身份的对应。距离门限为1米，只使用当时有观测支持的滤波轨迹位置。

IDF1综合身份精确率与召回率，越高越好。C1是单相机；B2使用C1+C2；B3使用C1+C2+C3，等权融合。三段分别独立运行、独立求身份对应：

| 片段 | C1 IDF1 | B2 IDF1 | B3 IDF1 |
|---|---:|---:|---:|
| 旧开发0–495 | 46.20% | 59.79% | 55.47% |
| 新开发500–795 | 41.96% | 61.81% | 60.17% |
| 已使用的对照片段800–1395 | 42.33% | 53.17% | 49.02% |

旧/新指本项目使用同场景片段的先后顺序；800–1395原在E003用于验证，后已用于分析比较。它不能再当作未使用测试段。

三相机在三个片段的IDF1均低于双相机，说明覆盖改善不自动转化为身份保持改善。完整“GT×预测”距离关系不能用帧内空间匹配的获胜配对代替；库里的身份切换计数也不等于看图确认的串人次数。近距离对应存在能力边界，见[评价协议](../../docs/EVALUATION.md)。
