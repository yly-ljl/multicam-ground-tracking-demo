# E002：增加相机，覆盖与错误一起变化

更新：2026-10-30。返回[实验索引](../README.md)。

在单相机闭环上加入同场景的第2、3号相机。双相机 B2 使用 C1+C2，三相机 B3 使用 C1+C2+C3。每个时刻按 C1→C2→C3 顺序合组，要求完整成员之间均满足0.75米几何门限，每个相机在一组中最多贡献一个观测，组位置取等权平均；未合组观测可单独保留。

在旧开发片段0–495的100个时刻中，使用整个地面评价区域的全部2152个GT（真实标注）人时刻。以下只统计当前有观测支持的滤波位置，采用1米内一对一匹配：

| 方案 | 位置匹配 | 未匹配预测 | 位置召回率 |
|---|---:|---:|---:|
| 单相机 C1 | 875 | 168 | 40.66% |
| 双相机 B2 | 1468 | 411 | 68.22% |
| 三相机 B3 | 1774 | 869 | 82.43% |

覆盖增加的同时，额外输出也增加。原案例中，帧120的不同人物相距0.7336米而被误融合；帧485的同人跨相机观测相距0.7978米，超过门限而分裂。几何距离不能单独确认身份。

[E004](../E004_identity/README.md)随后统一补充身份评价；[E007](../E007_observation_diagnosis/README.md)进一步拆分第三相机带来的新增和损失。原空间表见[E002_spatial.csv](../../results/summary/E002_spatial.csv)，身份比较见[详细结果](../../docs/RESULTS.md)，分母与匹配规则见[评价协议](../../docs/EVALUATION.md)。
